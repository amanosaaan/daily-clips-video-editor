# 動画編集アプリ(クリップ結合・Web版)

複数の動画クリップを撮影日順に結合し、撮影日の焼き込みやテキスト・図形・モザイクなどの
編集を加えて1本の動画として書き出す、ブラウザだけで完結する動画編集アプリです。

サーバーを使わず、動画のデコード・合成・書き出しまですべてブラウザ内(WebCodecs)で行うため、
GitHub Pagesのような静的ホスティングだけで公開できます。データはお使いのブラウザの
IndexedDBに保存され、外部のサーバーには送信されません。

## 現在の開発状況

このアプリは、ローカルで動いていたPython版の動画編集アプリ
(複数動画の結合・トリミング・回転・拡大縮小・位置調整・クロップ・文字入れ・図形・
モザイク・撮影日焼き込み・YouTubeチャプター生成など)の機能を、Web版として
段階的に移植している途中です。土台は姉妹アプリ
[storyboard-video-editor](https://amanosaaan.github.io/storyboard-video-editor/)
をベースにしており、UIデザイン・操作感をできるだけ揃えています。

現時点では姉妹アプリの土台をそのまま流用した最小構成の状態で、Python版特有の機能
(撮影日順の自動並び替え、撮影日焼き込み、モザイク、YouTubeチャプター生成など)は
今後のアップデートで順次追加していきます。

## セットアップ・開発

```bash
npm install
npm run dev      # ローカル開発サーバー
npm run build    # 本番ビルド
npm run test     # テスト実行
```

## デプロイ

`master`ブランチへのpushで、GitHub Actions (`.github/workflows/deploy.yml`) が
自動的にビルドしてGitHub Pagesに公開します。
